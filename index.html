Outreach Pipeline

Outreach Pipeline is a personal-use tool for the account owner to prepare and track individually reviewed professional outreach. It checks the owner's Gmail mailbox for replies and delivery notices, creates and verifies outgoing messages, and records delivery state so a recipient is not contacted again after a reply or other stop event.

Sending is controlled by the owner. The tool requires an approved draft, a verified recipient address, and an enabled sending control before it can send. It is currently paused.

This site provides information about the OAuth app used to connect the owner's Gmail account. See the privacy policy for the data handled by the tool.
